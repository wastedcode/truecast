# gold/ — the truecast gold catalog (prototype)

Plain-text, CC0 catalog of best-in-class public work, organised by **job**. Agents read `llms.txt` first;
everything is greppable Markdown with a small front-matter header.

- `entries/` — one file per exemplar (an artifact, a tool, or a source to search).
- `jobs/` — one card per job: what it is, synonyms to search by, the shelf, siblings, checks.
- `playbooks/` — jobs made of jobs (e.g. build a brand), with the gold for each step.
- `llms.txt`, `llms-full.txt`, `index.jsonl` — generated by `python3 gold/build.py`; `--check` fails on drift.

Linked works belong to their owners. We link to the owner's copy and an Internet Archive snapshot; we never
host copies. Catalog text is CC0-1.0.
