# Mailchimp brand assets — the minimal public page

**Why it's gold** (for the small job)
- Everything a partner or journalist needs on one page: the name ("one word, spelled with a big M and a little
  c"), always pair the name with Freddie, use the reverse version on dark, two named colors (Cavendish Yellow,
  Peppercorn), and four plain don'ts.

**Weakness**
- Not a guidelines system: no hex values, no construction, no type. Using it as the model for a full
  guidelines document would under-deliver; see the contrast with the NASA manual.

**Use when** you need a press kit or public brand page (brd-015), not internal guidelines.
