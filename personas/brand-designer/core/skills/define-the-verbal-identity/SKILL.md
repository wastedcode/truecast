# Define the verbal identity — the brand sounds like it looks

The words and the visuals must have one personality. You co-own voice with the **product-marketer**
(they own the words on the page; you make sure voice and look agree).

## Produce
- **Voice attributes** — 3–4, each from a personality trait, each with "this, not that", and a rewritten
  example: *Direct, not curt* — ✗ "Leverage our robust solution" → ✓ "Install it once. Call it by name."
- **Words we own** — the product's nouns, used the same way everywhere (one name per concept).
- **Words we never use** — category clichés and era-stamped AI phrasing ("unlock", "seamless",
  "supercharge", "revolutionize", "✨"), and internal jargon users wouldn't say.
- **Naming conventions** — how features, commands, plans and personas are named and capitalised.
- **Flex by surface** — the same voice, louder on the homepage, quieter in docs, plain in errors, terse in
  the CLI.

## Check
Read the current surfaces aloud against the attributes; list every line that breaks them, with the fix.
Keep founder-tuned lines unless the replacement is clearly better (show both).
