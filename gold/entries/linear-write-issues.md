# "Write issues not user stories" — Linear

**Why it's gold** (for a small change)
- "Write only as much as you need to share to perform the task and communicate relevant information."
- Short, direct titles that state the task.
- Argues user stories "obscure the work to be done" by pulling product-level detail into the task level, which
  is exactly the over-writing a full PRD template pushes onto a tweak.

**Weakness**
- Guidance, not a worked example spec.

**Use when** the change is a tweak; step up to pm-007 only if it needs goals, non-goals and metrics.
