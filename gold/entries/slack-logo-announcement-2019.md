# "Say hello, new logo" — Slack, 2019

**Why it's gold**
- The rationale customers read: old logo "hard to get right" (11 colors, a prescribed 18º rotation), variant
  versions that didn't match, recognition suffering.
- Says what was kept ("the spirit of the original", the hash that matches the channel marker) before what
  changed, which is how you announce a refresh without alarming existing users.

**Weakness**
- Marketing voice; no construction detail. Pair it with the Pentagram case study.

**Use when** writing the public rationale for a logo change (brd-050).
