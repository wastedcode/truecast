# Art-direct the visual — from "not slop" to work a top studio would sign

`refuse-ai-slop` is the floor: it removes the tells of "nobody decided." It does not make anything
*good*. A page with no gradient text, no Cardocalypse and no Inter-everywhere can still be forgettable.
Art direction is the affirmative half: **one idea, executed with conviction, in every detail.** The bar is
the best visual design shipping now — the studios and in-house teams whose launch pages other designers
screenshot (see `beat-the-frontier` for the current names; look at their latest work before you start).

## 1. Find the concept before touching pixels
- Write the **one-sentence visual idea** that comes from *this* product's substance: "a scanner — so the
  page reads like a terminal report that resolves into calm"; "a market — so everything is a live ticker."
  A concept you could paste onto a competitor's page is not a concept.
- Gather **references from outside the category** (print, editorial, signage, product packaging, film
  titles) and from the current best in the category. Note the specific *move* you're taking from each —
  never the look wholesale.
- Make **2–3 directions** that differ in concept, not just colour. Render each far enough to judge (hero +
  one section). Pick on the brief, and say why the others lost.

## 2. Build the system that expresses it
- **Type does the heavy lifting.** Pick a display face with character that fits the concept and a body
  face built for reading; set a modular scale from the content (the longest headline, the densest table),
  not a default ramp. Tight, deliberate leading on display; generous on body; real typographic details
  (true quotes, en-dashes, tabular figures for data, hanging punctuation where it shows).
- **Colour has a job.** A restrained base, one ownable accent that means something (action, brand, live),
  and a semantic set. Test it in light *and* dark. No framework default anywhere.
- **Real imagery over abstraction.** The actual product UI, real output, real data, real people's words —
  cropped and composed with intent. Bespoke illustration or diagrammatic art when it explains something
  (`explain-with-visuals`). Never stock, never blob gradients standing in for an idea. Never invent social
  proof (logos, stats, testimonials) — leave the slot out until a real one exists.
- **Composition with tension.** A grid you break on purpose; scale contrast (one thing very big);
  asymmetry where it adds energy; whitespace as an active element. Each section has one focal point
  (`compose-the-layout`), and the sections have rhythm — not the same card row five times.
- **Motion as information.** Animate what explains (the scan resolving, the number counting to its real
  value, the before→after) and nothing else. Respect `prefers-reduced-motion`.

## 3. Render it and look — then refine, repeatedly
You are not done when the code compiles. **Render it and look at the screenshot** at 375, 768, 1280 and
1440+ widths, light and dark (Playwright/headless browser via Bash; Read the PNG). For each render:
- Squint: does the eye land on the one thing that matters? Is anything competing?
- Pixel audit: dead or blocky whitespace, squished or overlapping elements, orphans/widows in headlines,
  two treatments for the same kind of thing, misaligned baselines, inconsistent radii or icon weights.
- Hold it next to the frontier exemplar you named. Where does theirs feel more considered? Fix that, then
  re-render. Stop when a side-by-side wouldn't embarrass you — and you can name where yours goes further.

## The critique pass
- Could this page belong to a competitor with the logo swapped? → the concept isn't in it yet.
- Is every image real, every number sourced, every logo/testimonial genuine?
- Does the type scale come from this content? Is there one confident move a viewer will remember?
- Did you render and inspect every breakpoint and both themes, and fix what you saw?
- Would the designer you named as the benchmark ship it? What would they change? Change it.
