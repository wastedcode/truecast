# truecast brand

Everything here is generated by `scripts/brand/build.py` from the repo itself. Re-run it when a
playbook changes, and run `scripts/brand/check_contrast.py` when a colour changes. The rendered system
is at [`/brand/`](index.html) (`?theme=dark` forces dark).

## The idea

**Depth you can see behind every name.**

A teammate is two things: the name you call (`@security-engineer`, one agent file Claude Code sees)
and the playbook under it (21 files, 12,697 words). A one-file agent is mostly its name; truecast shows
what's under it. The two most-starred free collections ship one file per agent: VoltAgent's
[`security-engineer.md`](https://github.com/VoltAgent/awesome-claude-code-subagents/blob/408d3c9eee2d0c75c12a3abb5de29e53c2ca6b9e/categories/03-infrastructure/security-engineer.md)
is 1,007 words (the one the [proof](../proof/README.md) ran) and wshobson's
[`security-auditor.md`](https://github.com/wshobson/agents/blob/044b4b21f083948e69ec878a7b07c8d0951a6ffa/plugins/security-scanning/agents/security-auditor.md)
is 1,146 (`curl … | wc -w` at the pinned commits, checked 2026-10-16).

**Personality.** *Exact, not cold* (numbers you can check) · *candid, not modest* (shows the receipt,
including where it lost) · *expert, not exclusive* (plain words, real output) · *quiet, not timid* (one
colour, used hard).

**Principles.** Every graphic is a real artifact of the product. Type does the work; decoration doesn't.
One blue, and nothing warm. If it can't be checked, it doesn't ship.

## Why these choices

- **True blue (`#1F36FF`).** "True blue" means genuine. In the category map (live homepages
  captured 2026-10-16: Claude Code, Anthropic, Cursor, Vercel, Resend, Warp, Ghostty, Railway, Raycast,
  Bun, Cline, Devin, Factory, Fly, Oxide, Tailscale, opencode, buildwithclaude; plus favicons from Linear
  and Zed) the grounds are near-black or warm off-white, and the accents are purple, orange or green. Nobody owns a
  saturated ultramarine. It's also the opposite of the platform's own warm cream and terracotta, so
  truecast never looks first-party. The old amber-on-charcoal sat right next to Claude's palette.
- **The mark is a T, cut where the playbook is.** The crossbar is the agent file (the surface); the
  stem is the playbook beneath it, cut where skills end and knowledge begins: 8:2 on a 14-unit grid (the favicon re-draws it 5:1 for 16px).
  Across all 12 playbooks, skills to knowledge runs 81:19 (agent files excluded: they're the crossbar, not
  the stem; `build.py` computes it from `cores.json` and prints it on [`/brand/`](index.html)). It's the device
  (below) reduced to one teammate.
- **Schibsted Grotesk** (display and text): a grotesk from a media group's print heritage. It reports;
  it doesn't pitch. **Martian Mono** (width 87.5) for everything you'd type or read in a terminal. It's
  sturdy enough to sit beside the grotesk, and it isn't the category default (JetBrains, Geist, Berkeley).
  Both are OFL and self-hosted.

## Equity audit: what existed, what we kept

Little exposure (8 GitHub stars, no favicon, no social image), so we could move further than an
established brand.

| Asset (where) | Decision | Reason |

## Tokens

[`tokens.css`](tokens.css) is the only source. Use roles (`--color-text`, `--color-accent`, `--color-fill`…),
never raw hex. Light is the default and dark follows the system; `data-theme="light|dark"` on `<html>` forces one.

| Role | Light | Dark |
|---|---|---|
| bg / surface / surface-2 | `#FFFFFF` / `#F5F6FA` / `#ECEEF5` | `#0B0D1A` / `#12152A` / `#1A1E36` |
| text / text-2 / text-3 | `#0B0D1A` / `#474B5E` / `#62667A` | `#F3F4FA` / `#B4B8CC` / `#8A8FA8` |
| accent (links, focus, mark, device) | `#1F36FF` | `#8C9BFF` |
| fill + on-fill (primary button, blue fields) | `#1F36FF` + white (6.9:1) | same |
| verdicts: go / conditional / no-go | `#0B6E3A` / `#8A5300` / `#C01522` | `#5DD497` / `#F2BA55` / `#FF8A8A` |
| the ink field (the roster) | `#0B0D1A` ground, dark text roles, accent `#8C9BFF` | `#12152A` ground (ink-900, one step off the page), same roles |

All 77 allowed pairings pass AA (`scripts/brand/check_contrast.py`). `--color-text-3` is not allowed on `surface-2`.
**Forbidden:** true blue `#1F36FF` on ink (2.79:1). On dark grounds the brand is `#8C9BFF`, or a solid blue *field*.
The verdict colours appear only on verdicts and the grades they rest on (GO, CONDITIONAL, NO-GO; P0–P3,
Medium/High…), never as decoration: not on "Copied", not on a CLI checkmark. Every verdict colour is a
primitive in `tokens.css` (`--tc-go`, `--tc-go-light`, …); the field and the page point at those, never at raw hex.
The ink field never sits on a second blue: in dark mode it's ink-900, kept apart from the page by its 3px
accent surface line at the top edge. `--tc-blue-deep` stays a wash behind light-blue text.

**Type.** Display 800, tracking −0.035em, leading 1.0 (`--text-display`, 44→92px). H2 800, −0.025em.
Body 400 at 17/1.55, measure 64ch. Mono at `--mono-scale` (0.86em) inline. Weights in use: 400, 600, 800.
Martian has no `↗ ✔ ≥`; the stack falls back to the system mono for those, which is fine.

**Shape.** Square on purpose: radius 2px (pills, tags) and 4px (buttons, cards), 8px only for large panels.
Rules: a 1px hairline, and the 3px **surface line**.

**Motion.** Hover 120ms, reveals 200ms, `cubic-bezier(.2,0,0,1)`. The one signature motion is
**the drill**: on first view, a core's bands appear top to bottom (`scaleY` from 0, origin top, 360ms each,
28ms stagger), once. Under `prefers-reduced-motion` the tokens zero the durations: the core is simply there.

## The mark

| File | Use |
|---|---|
| `logo.svg` / `logo@2x.png` | blue mark + ink wordmark, on white and light surfaces |
| `logo-dark.svg` / `logo-dark@2x.png` | `#8C9BFF` mark + `#F3F4FA` wordmark, on ink |
| `logo-on-blue.svg` / `logo-on-blue@2x.png` | all white, on a true-blue field |
| `logo-mono.svg`, `wordmark.svg`, `mark.svg` | `currentColor`: inline them and set `color` |
| `favicon.svg`, `favicon.ico` (16/32/48), `apple-touch-icon.png`, `icon-192/512.png`, `icon-maskable-512.png`, `site.webmanifest` | the app-icon tile: white mark on blue, 3-unit margin |

- **Construction.** The mark stands exactly as tall as the wordmark's t, and the gap between them is 4 mark
  units. The wordmark is Schibsted Grotesk 800, outlined, tracked −28/1000, then spaced by eye: u‑e −18,
  r‑u −8, t‑r −6, c‑a +3, a‑s +3, s‑t +12. Don't retype it in the font.
- **Clear space:** the mark's width on all sides of the lockup. **Minimum:** lockup 80px wide; mark 12px; tile 16px.
- **Don't:** recolour it outside the three versions · put the blue mark on ink · stretch it, or set the
  wordmark in another face · add a `>` or a cursor · put it on photos or illustrations without a blue plate
  (tested: it fails on busy imagery) · round the mark's corners, or rebuild it from fewer or more bands.

## The device: the core

Every teammate is drawn as its real playbook, hanging from a surface line: one band per file in
`personas/<name>/core` (agent.md, then skills, then knowledge), each as tall as its word count. Files:
`cores.svg` (all twelve at 40 words/px), `cores/<name>.svg`, `cores/handwritten.svg` (the 76-word agent from
the proof run), `depth-compare.svg`, and the numbers in `cores.json`. Every band carries
`data-path` and `data-words` for tooltips. The SVGs use `currentColor`, so set `color: var(--color-accent)`.

- **Right:** the hand-written agent and `security-engineer` side by side at one scale (a hairline next to
  21 bands). The twelve in a row as the teammate section's index. One core beside its teammate's row.
- **Wrong:** different scales in one view · bands drawn by hand or "for texture" · cropping a core
  inside a layout (it may run off a frame's edge, as on the social card) · colouring bands by teammate.
- **On its side.** Where a row of text needs its teammate's shape (the roster, Fig. 2's column heads, a
  phone-width Fig. 1, the share card), the core lies flat: the surface line stands at the left and the
  bands run right, still one band per file, at one scale per view. Same device; scale truth, not
  orientation, is the rule. The page's drawings are generated by `scripts/brand/page.py`.
- **Read vs not read.** When a drawing shows what a run opened, opened bands are solid and the rest are
  drawn hollow (1px outline in the same colour), never faded: a faded band fails 3:1.
- **In copy, call it the playbook.** "Core" is the device's design name; readers see "playbook"
  (the copy deck's one-term-per-concept rule). Caption it plainly: `one band per file`.

## Imagery

Allowed: real output, verbatim and labelled (or labelled "trimmed"); real file trees; the core; the mark.
Not allowed: fake Claude Code UI chrome · stock photos, 3-D, gradients, glows · ✨ and other AI sparkles ·
robots and mascots · Anthropic's marks · any number, logo or quote we can't source.

## Voice

The product-marketer owns the words; this is the shared voice. A maintainer talking to another developer:
plain, specific, dry, a little blunt. It shows real output instead of describing it. Words and look share one
personality: exact, candid, plain, quiet.

| Attribute | ✗ | ✓ |
|---|---|---|
| Exact, not cold | "Deep expertise built in" | "17 skill files and 3 reference notes, 12,697 words" |
| Candid, not modest | "Finds more bugs" | "The other two listed more small items (7 each, to our 4)." |
| Plain, not flat | "Unlock powerful AI teammates" | "Install a specialist with one command and call it by name." |

Words we own: **teammate · playbook · brief · plan · verdict · by name**. Never: unlock, supercharge,
seamless, powerful, AI-powered, 10x, magic.

  ```html
  <link rel="stylesheet" href="/brand/tokens.css">
  <meta property="og:image" content="https://truecast.dev/brand/og.png">
  <meta name="twitter:card" content="summary_large_image">
  ```
  `/favicon.ico` is also at the site root for crawlers.
- **Social card** `og.png` (1200×630): the H1 next to all twelve playbooks, running off the bottom edge.
  `github-social.png` (1280×640) is the same card for the repo. The site shares `og.png`. (A receipt card
  with the first proof run's grades was retired on 2026-10-16: that run's briefs differed, and the fair
  rerun is a tie that a share card can't carry honestly in one glance.)
- **README header** `readme-header-light.png` / `-dark.png`: transparent, wired in `README.md` with
  `<picture>`. The tagline stays as text underneath.
- **CLI** (a proposal for the engineer, not yet in code): plain by default. Teammate names in bold ANSI
  blue (34). Labels (`craft`, `record`, `pointer`, `agent`) dim. GO, CONDITIONAL and NO-GO in ANSI
  green, yellow and red, and only on those words. 16-colour only; none when `NO_COLOR` is set or stdout isn't a TTY.
  The rendered proposal is on the touchpoint board (`scripts/brand/board.py`).
