# Build a brand

Run the steps in order; each step's output is the next step's input. Pull the step's shelf before you start it.

1. **brd-004 Creative brief** from a discovery questionnaire (no public gold: required shape + judge)
2. **brd-003 Competitive landscape** (search Brand New, Logobook)
3. **brd-001 Brand platform** (low gold: the Collins strategy sentence is the move)
4. **brd-006 Logo and wordmark** — or **brd-010** if refreshing an existing mark
5. **brd-011 Type** and **brd-012 Color**
6. **brd-014 Guidelines**
7. **brd-017 Voice and tone**
8. **brd-050 Rationale** to launch it

**Keep one system.** If you pick an exemplar for step 4, follow its `same_system` links for later steps
before mixing sources: Mailchimp's identity, brand page and content style guide are one coherent system.
