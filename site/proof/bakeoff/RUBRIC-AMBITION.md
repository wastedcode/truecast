# Ambition re-judging rubric — sealed 2026-10-17 before any ambition judging

Same 8 blind decks. The question is no longer "fewest things wrong" but "the most original idea that holds up."
An OK deck with no defects ranks BELOW a deck with a frontier-beating idea that needs a few fixes.

Each judge reads ALL eight decks side by side (order shuffled per judge), plus any new evidence a run created
(blind/evidence/<deck>/ — this ships with the page; it is a strength, not a missing receipt).

Per deck, score 1–10:
- ORIGINAL: would the best developer-tool marketer alive have proposed this unprompted? 10 = nobody in the category has done it.
- FRONTIER: does the page it describes beat the homepages of Linear, Stripe, Vercel, Resend, Cursor and Bun at their own game, idea for idea?
- HOLDS: is the boldest idea true and defensible with at most a few fixes? (Defects count only if they break the big idea.)
- MOVES: would it make a Claude Code user install, more than the others would?
Overall rank 1–8 (1 = best), judged on the boldest idea that holds, not on polish.

Anti-hedging rules: before ranking, the judge must (1) name the riskiest deck and make the strongest case FOR it, (2) name the
safest deck and make the strongest case AGAINST it, and only then rank. A tie or "all similar" is not an allowed answer.
The judge also names the single best idea across all eight decks, and what an even bolder version of it would be.
